# Inventory Browser Update

The Egg Inventory page now uses a card/grid browser inspired by the supplied reference image.

Features:
- Account tabs: All + each connected account.
- Rarity filter chips with counts.
- Search box for egg names.
- Rarity-colored cards and borders.
- Egg images continue to use the Eldorado image proxy/catalog.
- Inventory count updates with the active filters.
- Responsive horizontal filters on mobile.
