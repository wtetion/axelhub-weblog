AXEL HUB WEBLOG — CLOUDFLARE DEPLOY

A. Install / login
1) Install Node.js 18+
2) In this folder run:
   npm install
3) Login:
   npx wrangler login

B. Create D1
4) Run:
   npx wrangler d1 create axelhub-weblog
5) Copy the returned database_id into wrangler.jsonc:
   "database_id": "YOUR_D1_DATABASE_ID"

C. Secret
6) Run:
   npx wrangler secret put AUTH_SECRET
7) Paste a long random secret when asked.

D. Database migration
8) Run:
   npx wrangler d1 migrations apply axelhub-weblog --remote

E. Deploy
9) Run:
   npx wrangler deploy

F. Open site
10) Open the workers.dev URL shown by Wrangler.
11) Create an account at Sign up.
12) Copy the Telemetry Key from the dashboard.

Luau G Config example:

getgenv().AxelWebLogConfig = {
    Enabled = true,
    URL = "https://axelhub-api.YOURNAME.workers.dev/api/telemetry",
    Key = "axel_your_personal_key",
    Interval = 5,
    Debug = false,
    LocalFallback = true,
}

Every user uses the same URL. Each account has a different Key.

Custom domain example later:
https://api.axelhub.com/api/telemetry

Only URL changes. User Key stays the same.
