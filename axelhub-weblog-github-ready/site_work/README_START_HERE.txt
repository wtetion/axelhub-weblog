AXEL HUB WEB LOG - START HERE

1) Deploy this repository as a Node.js web service.
2) Configure PUBLIC_BASE_URL=https://Axelhub.ud0 and persistent DATA_DIR.
3) Open https://Axelhub.ud0.
4) Sign up or sign in.
5) Copy your personal Telemetry Key into WEBLOG_API_KEY in the Luau script.
6) Keep WEBLOG_URL=https://Axelhub.ud0/api/telemetry.

Each Web Log user has a separate private namespace; accounts, inventory, events, analytics and graph data are isolated per user.
