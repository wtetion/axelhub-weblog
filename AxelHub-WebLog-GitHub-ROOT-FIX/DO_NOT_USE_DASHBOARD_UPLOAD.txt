IMPORTANT - CLOUDFLARE DEPLOYMENT

This project is NOT meant to be deployed with the Cloudflare Dashboard "Upload and deploy" drag-and-drop page.
That uploader rejects projects that require Wrangler/build configuration (including wrangler.jsonc and D1 bindings).

Use ONE of these methods:

1) Windows one-click:
   Double-click DEPLOY_NOW.bat

2) Terminal:
   npx wrangler login
   npx wrangler d1 create axelhub-weblog
   npx wrangler d1 migrations apply axelhub-weblog --remote
   npx wrangler deploy

The included SETUP_CLOUDFLARE.ps1 can automate D1 creation, AUTH_SECRET setup, migrations, and deployment.
